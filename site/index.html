Free and open source

Your Galaxy desktop, in any browser.

Samsung stopped making its DeX apps for Windows and Mac. DeXterous brings DeX back. Plug in your phone, run one command, and a full desktop opens in a browser tab.

$ npm install -g @subsneaker/dexterous
$ dexterous
$ npx @subsneaker/dexterous@latest

How it works

Three steps, about five minutes.

Do the first one once. After that, it is just plug in and go.

  1. 1

    Turn on USB debugging

    This lets your computer talk to the phone. Open Settings, then About phone, then Software information. Tap Build number seven times. Back in Settings, open Developer options and switch on USB debugging.

    If it will not stay on, check Auto Blocker in Security and privacy. Turn it off while you use DeXterous.

    1. Settings
    2. About phone
    3. Software information
    4. Build number tap 7 times
    then back to Settings
    1. Developer options
    2. USB debugging
  2. 2

    Run dexterous

    Plug the phone in and unlock it. Tap Allow when it asks about USB debugging, and tick Always allow from this computer (that is the phone's own wording). Then open a terminal and run the command. It starts a small server on your computer and opens a browser tab. Keep the terminal open while you use DeX.

    First time? Install it once with npm install -g @subsneaker/dexterous.

    Terminal
    $ dexterous

  DeXterous v0.1.0

  Open DeXterous in your browser:
    http://localhost:8686/

  adb server:  127.0.0.1:5037  reachable
  3. 3

    Pick your phone, press Start DeX

    Choose your phone from the list and press Start DeX. If the phone is locked, unlock it. DeX appears in the tab and follows the size of the window. Press Ctrl Alt / to see every shortcut.

    When you are done, close the tab. Your open apps move back to the phone.

What you get

A real desktop, not a mirror.

Most tools copy your phone screen to the computer. DeXterous does something else. It gives the phone a second, virtual screen, and DeX runs on that. You get a desktop. The phone stays a phone.

Windows, taskbar, right-click
Move, resize and snap windows. Hover and right-click menus work like on a computer.
Your phone stays usable
Calls and messages still reach you. You can use the phone while DeX runs.
Fits your window
Resize the browser tab and the desktop resizes with it.
Keyboard, mouse and touch
Type, scroll and use shortcuts. On a Mac, ⌘C and ⌘V work like Ctrl. Touch screens work too.
Sound
The phone's audio plays in the browser. One button mutes it.
One clipboard
Copy on the phone, paste on the device you're using, and the other way round. Or keep them apart.
Smooth video
Your browser decodes the video with hardware help, at up to 120 frames a second.
Respects the lock screen
When the phone locks, DeXterous covers the desktop, blocks input and mutes sound until you unlock.
Stays on your computer
By default it only listens on your own machine. No account. No telemetry.

What you need

A Galaxy phone, a cable and two small tools.

  • A Galaxy phone or tablet

    It must run One UI 8 or newer. That is the first version where DeX can use a virtual screen. Check under Settings, About phone, Software information.

  • A USB cable

    USB is the easiest way to start and the smoothest to use. Wi-Fi works too, once you have set it up.

  • A computer with Node.js and adb

    Node.js 22.18 or newer runs DeXterous. adb (Android platform-tools) is how it talks to the phone. Pick your system on the right.

  • A modern browser

    Chrome, Edge, Opera, Safari 17 or newer, or Firefox 130 or newer. So far it has been tested in Chrome on a Mac.

Install Node.js and adb

$ brew install node
$ brew install --cask android-platform-tools

No Homebrew? Get Node.js from nodejs.org.

Install Node.js and adb

> winget install OpenJS.NodeJS.LTS
> winget install Google.PlatformTools

Open a new terminal afterwards. If the phone does not show up, install Samsung's USB driver for Windows.

Install adb (Debian and Ubuntu)

$ sudo apt install android-tools-adb

Fedora: sudo dnf install android-tools. Arch: sudo pacman -S android-tools. Or use Google's platform-tools zip.

Many distributions ship an old Node.js. Check with node --version. If it is below 22.18, use nvm.

Another screen

Use it from an iPad or another computer.

The phone stays plugged into one computer. That computer runs DeXterous. Any other device on the same Wi-Fi can open DeX in its browser.

  1. On the computer with the phone, run dexterous --lan.
  2. It prints a link that starts with https://. Open that link on the iPad.
  3. Your browser warns about the certificate. Accept it once.

The link holds a secret token. Treat it like a password. Allow incoming connections in the computer's firewall.

$ dexterous --lan

Not tested on an iPad yet

Safari and iPad can refuse a self-signed certificate for the live connection. If yours does, use a certificate your iPad trusts, made with mkcert or Tailscale. The guide shows how. DeXterous is meant to work on an iPad, but nobody has tried it on a real one yet. So far it has been tested in Chrome on a Mac.

Nothing to install

Or try it right in your browser.

There is a browser-only version. It talks to your phone over USB with no server in between. It is good for a quick look. The installed command works in every browser and over Wi-Fi.

Open the browser version

Before you click

  • Chrome or Edge only.
  • USB cable only.
  • Run adb kill-server first. Your computer's adb must not be holding the phone.
  • You still need USB debugging on the phone.

Questions

Good to know.

Is it safe?

The code is open, so anyone can read it. By default DeXterous only listens on your own computer. It has no telemetry and sends nothing to us. The only thing it asks the internet is npm, about once a day, for the latest version number, and you can turn that off. On the phone it uses the stock scrcpy server, the same tool many developers use.

One thing to know. Whoever can reach DeXterous can control your phone through adb. So keep the --lan link private and never put it on the internet.

Does it need root?

No. You do not root the phone and you do not install an app on it. You only switch on USB debugging.

Which phones work?

Galaxy phones and tablets on One UI 8 or newer. Older versions only show a plain launcher on the second screen, and DeXterous will tell you the phone refused. So far it has been tested on a Galaxy Z Fold8 with One UI 9. Other models should work, but haven't been tested.

Does it work over Wi-Fi?

Yes. Turn on Wireless debugging on the phone, then use Add a phone over Wi-Fi on the DeXterous page. The first time, you also enter the pairing code the phone shows. USB is smoother. On Wi-Fi, pick the Balanced picture quality.

Does it cost anything?

No. DeXterous is free and released under the MIT license. There are no accounts and no ads.

Is this from Samsung?

No. DeXterous is an independent project. It is not affiliated with or endorsed by Samsung. It works with the DeX feature that is already built into your phone.

Something is not working. Where do I look?

The troubleshooting guide covers the common problems, such as no phone in the list or a locked phone. If that does not help, open an issue.
