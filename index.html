Add a phone over Wi‑Fi

Your phone and the computer running DeXterous need to be on the same Wi‑Fi. On the phone, open Settings › Developer options › Wireless debugging and turn it on.

First time pairing this phone?

Tap Pair device with pairing code on the phone. It shows a pairing address and a 6-digit code. Enter both, and keep that window open until it works.
