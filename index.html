Add a phone over Wi‑Fi

Your phone and the computer running DeXterous need to be on the same Wi‑Fi. On the phone, open Settings › Developer options › Wireless debugging and turn it on.

First time pairing this phone?

Tap Pair device with pairing code on the phone. It shows a pairing address and a 6-digit code. Enter both, and keep that window open until it works.

Set up DeXterous first

DeXterous is a small program that runs on your computer. It connects to your phone over USB or Wi‑Fi and works in any browser.

You need Node.js 22.18 or newer and Android platform-tools. Then install and start it:

npm install -g @subsneaker/dexterousdexterous

dexterous opens DeXterous in your browser, at http://localhost:8686.

Install steps for macOS, Windows and Linux

On Chrome or Edge, you can also use USB, browser only right here, with nothing to install.
